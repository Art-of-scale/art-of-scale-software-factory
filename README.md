# Art of Scale Software Factory

Your own software factory: your code, your live app, your database, and the **Art of Scale Coding Coach** in every session.
For founders and leaders who don't write code. Part of the Art of Scale Factory Playbook.

## Load your factory (about 5 minutes)

**[Load my Art of Scale Software Factory](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FArt-of-scale%2Fart-of-scale-software-factory&project-name=my-software-factory&repository-name=my-software-factory&stores=%5B%7B%22type%22%3A%22integration%22%2C%22integrationSlug%22%3A%22supabase%22%2C%22productSlug%22%3A%22supabase%22%7D%5D)**

1. Sign in to Vercel with GitHub. Keep the repo **private**.
2. When asked, add **Supabase** (a new project, for made-up data only).
3. Click **Deploy**. Open your live link: the status board shows Code, Hosting, Database and Coach.
4. Open Claude Code (desktop app → Code → cloud session, or claude.ai/code), choose your new repo, and paste:

> Start my software factory. Read CLAUDE.md, install the factory if it is not installed yet, then run the sf-start skill and guide me step by step.

No Supabase step in the Vercel flow? After the deploy: Vercel → your project → **Storage** → **Connect database** → Supabase → Create. Then redeploy.

## Rules
Made-up data only until the Art of Scale Production-Ready Gate. Never paste keys or passwords into chat. Only the public Supabase key goes into Vercel.
