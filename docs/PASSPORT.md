# Factory Passport

Your factory's journey on the Art of Scale Software Factory Ladder. Your live status page shows it, and it updates on every deploy.

- **Machine checks** tick themselves from the repo and the live settings.
- **Coach ticks** are below. The Coach ticks a step only after it has seen the proof (for example, `sf-level`, `sf-ship` or `sf-wrap`). Never tick a step to make the board look better.

Tick format: `- [x] id · note with the evidence and date`.

## Level 2 · Starter factory
- [ ] l2-live · App live on its own web address (tick when the Owner confirms the live link)
- [ ] l2-db · Database connected, public key only (tick when the status page shows Database ✓)

## Level 3 · Intent-first
- [ ] l3-plan · The agent plans before it edits
- [ ] l3-wrap · Each session ends with a wrap note
- [ ] l3-user · One real user tried the app (still made-up data)

## Level 4 · Self-checking
- [ ] l4-review · A fresh reviewer checks Medium and High changes
- [ ] l4-preview · Every change gets a preview link, merged by the Owner

## Level 5 · Governed
- [ ] l5-main · Main is protected: pull request and the Owner's merge
- [ ] l5-backup · Backups on, and one restore tested
- [ ] l5-alerts · Error alerts reach a named person
- [ ] l5-engineer · Engineer check before go-live
- [ ] l5-gate · Production-Ready Gate passed
